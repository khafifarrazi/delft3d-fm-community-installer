# 🛡️ Kebijakan Keamanan & Privasi Data (Security & Privacy Policy)

## Komitmen Privasi
Proyek repositori pengemasan komunitas ini berkomitmen penuh terhadap perlindungan data pribadi (*Personal Identifiable Information / PII*) dan hak kekayaan intelektual:

1. **Tanpa Kredensial Pribadi**: Repositori ini dan berkas installer yang didistribusikan **TIDAK PERNAH** memuat file lisensi pribadi, nama pemegang lisensi perorangan, email, maupun token akses sensitif.
2. **Lisensi Resmi Mandiri**: Setiap pengguna diarahkan untuk mendaftarkan lisensi resmi mereka sendiri secara langsung dari portal resmi pemegang hak cipta ([Deltares](https://download.deltares.nl/)).
3. **Integritas Biner**: Berkas biner installer yang dirilis melalui GitHub Releases selalu disertai nilai hash kriptografi (SHA256) untuk menjamin integritas dan keamanan dari modifikasi pihak ketiga.

## Melaporkan Masalah Keamanan
Jika Anda menemukan kerentanan keamanan, kebocoran data sensitif, atau pelanggaran ketentuan lisensi dalam repositori ini, mohon untuk segera melaporkannya melalui GitHub Issues dengan label `security` atau menghubungi pengelola repositori secara langsung.
